## 非技术用户操作流程

1. 在 LoreDock 新建一个专用于验收的知识库，导入不含个人信息的文本。
2. 创建只读连接，只勾选该测试知识库。
3. 点击“复制连接说明”，粘贴到目标 Agent，并批准需要的配置变更。
4. 保留原有 MCP 服务，不覆盖整个配置文件；不要提供管理令牌或读取系统凭据内容。
5. 必要时按客户端要求重新加载 MCP 或重开会话，观察真实工具调用记录。

建议测试文本：`moonstone 的保留期为 17 天。到期后由资料管理员确认归档。`

建议提问：

> 请仅通过 LoreDock MCP 查找 moonstone 的保留期，先搜索，再用搜索结果返回的引用读取原文。回答保留期和到期处理方式，并提供来源名称与定位。不要直接打开本地知识库文件。

## 验收清单

- 能看到 `list_libraries`、`search_knowledge`、`read_source` 的真实调用，而不仅是模型文字声称调用。
- 回答为 17 天，并给出管理员确认归档的信息；来源 ID、文件名、定位与导入文本一致。
- 只列出授权知识库；不能用另一个库 ID 读取资料。
- 关闭 LoreDock 后工具返回错误，不编造新查询结果；重新打开后可以继续读取。
- 撤销连接后新调用失败；客户端里残留配置不会重新获得授权。
- 验收完撤销测试连接；如删除客户端配置，只删除对应测试服务条目。

记录客户端版本、平台、结果、错误码与必要的脱敏工具证据。不要提交真实用户查询、令牌或模型完整响应。搜索质量调优仍单独后置，不在这一轮凭个例改权重。

## 配置依据与限制

Codex 使用 `[mcp_servers.<name>]` 的 `command` 和 `args` 表达 stdio 服务，也提供 `codex mcp add`；见 [官方 MCP 文档](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)。本机的临时 `-c` 参数解析验证不写入配置、不启动模型，也不算连接成功。

Cursor 本机 `--help` 显示 `--add-mcp` 能添加定义，但此次未修改用户 profile。当前自动化环境没有原生桌面 UI 控制能力，不能以读取帮助替代 GUI 会话验收。若改用非交互客户端，应先确认登录、模型调用范围及隔离配置方式。
