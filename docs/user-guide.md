# LoreDock 用户指南

## 开始使用

1. 安装并启动 LoreDock。应用会自动启动本地 Core，不需要命令行、Docker、Python 或额外数据库。
2. 新建知识库并使用“导入资料”添加文件、网页或文件夹。
3. 等待任务显示完成后，在搜索框输入问题或关键词。
4. 点击搜索结果查看原文片段、页码或字符位置。

支持 Markdown、TXT、PDF、DOCX、PPTX、XLSX、HTML/HTM，以及公开 HTTP/HTTPS 网页快照。一次性文件夹导入只读取本次选择的目录，不会持续监听。

## 搜索模式

默认混合搜索结合全文与本地向量检索。模型不可用时仍可使用 BM25 全文搜索。搜索结果的相关度不是概率；引用位置以结果中的来源和范围为准。

## 资料管理

“最近使用”记录主动打开过的资料，“收藏”保留手动标记的资料。删除资料会同时清理其解析产物和索引；删除知识库会删除该库中的全部资料。

## 备份与恢复

在“设置 → 备份与恢复”中可以立即备份、验证已有备份或选择备份恢复。恢复前 LoreDock 会先保存当前状态，再重启 Core 并切换数据。恢复完成后应检查知识库、资料和搜索结果。请勿在应用运行时手工复制 SQLite 主文件。

## Agent 连接

需要让 Codex 等 Agent 读取知识库时，请按照 [Agent 接入指南](agent-setup-guide.md)创建只读、按知识库授权的连接。

遇到启动、导入、搜索、模型或连接问题时，参见[故障排查](troubleshooting.md)。
