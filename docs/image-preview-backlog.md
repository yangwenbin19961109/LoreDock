# 搜索关联图片展示优化

## 状态与范围

- 状态：已记录，后续批次实现。
- 优先级：Phase 5 完整资料处理能力的非阻塞增强。
- 产品决定：不引入本地 OCR，不识别图片文字，也不使用视觉模型生成图片描述。

## 目标

导入 PDF、DOCX、PPTX、XLSX、HTML 或 Markdown 资料时，保留可安全提取的内嵌图片及其来源位置关系。用户搜索命中文本后，右侧预览除定位文字外，还可以展示命中页、幻灯片、工作表或相邻结构中的相关原图，帮助用户核对上下文。

图片本身不参与关键词或向量检索。是否展示图片由已命中的文字范围与图片锚点关系决定，不能声称系统理解了图片内容。

## 建议实现

1. 为派生图片保存稳定 ID、来源 ID、媒体类型、内容哈希、宽高和有界文件大小。
2. 保存格式相关锚点：PDF 页码、PPTX 幻灯片、DOCX 段落/关系、XLSX 工作表与绘图锚点、HTML/Markdown 相邻节点。
3. 搜索仍按现有文字索引排序；结果命中后按同页、同结构块或最近锚点查询图片。
4. 右侧预览以缩略图展示，用户点击后查看受限尺寸原图；明确标注图片来自哪个页面或结构位置。
5. 图片属于可重建派生产物，原始资料继续作为事实来源。删除、替换和重建来源时同步清理图片、缩略图与锚点。

## 安全与验收边界

- 不加载 HTML 外链图片，只处理已随原始资料保存且通过容器边界校验的资源。
- 校验媒体类型、文件签名、像素数量、解码尺寸和压缩比，防止图片解码炸弹；SVG 等主动内容不得直接执行。
- 限制单条结果和单个预览区域展示的图片数量，使用懒加载和缩略图，避免大文档拖慢搜索界面。
- 无图片或图片解析失败时，文字导入、索引、搜索和引用必须继续可用。
- 验收至少覆盖同页多图、跨页图片、重复图片、超大图片、损坏图片、来源删除和索引重建。

本功能不包含 OCR、视觉问答、图片语义搜索、自动图片说明或图表数据提取；如未来需要，必须重新进行产品决策与隐私、模型体积和检索质量评估。
