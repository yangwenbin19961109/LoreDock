# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

面向非技术用户和使用个人知识库的 AI Agent。桌面应用使用 React 界面与 Tauri 外壳，不开发移动端。

## Product Purpose

LoreDock 管理本地资料，通过带来源引用的检索为用户和 Agent 提供知识。

## Capabilities and Constraints

Agent 连接由用户选择知识库后创建。用户复制一段说明给 Agent，由有相应能力和权限的 Agent 配置 MCP。复制内容不得包含令牌；连接必须可以撤销。普通用户不需要理解向量和数据库。

## Brand Commitments

沿用当前已验收的主界面、组件和图标，不重新设计视觉风格。用户确认直接编写界面，不先生成效果图。

## Product Principles

- 本地优先，原件为事实来源。
- Agent 默认只读、按知识库授权。
- 清楚区分开发入口、配置已生成与实际连接成功。
- 不因生成说明而自动修改外部 Agent 的配置。
