# Agent 接入指南

## 创建连接

1. 保持 LoreDock 桌面应用运行。
2. 打开“Agent 连接”，选择允许读取的知识库。
3. 输入便于识别的连接名称并创建连接。
4. 复制 LoreDock 生成的配置说明，按 Agent 客户端要求合并到其 MCP 配置中。
5. 在 Agent 中调用 `list_libraries`，确认只能看到已授权知识库，再执行一次搜索和引用读取。

连接凭据保存在操作系统凭据库，复制说明不包含明文令牌。Agent 只能使用只读工具，不能创建、修改或删除 LoreDock 资料。

## 使用范围

当前已验证 Windows 上的 Codex 接入。Cursor 配置模板可生成，但实机验收仍暂缓。连接要求 Agent 与 LoreDock 位于同一台电脑和同一系统用户下；LoreDock 关闭时本地 MCP 不可用。

## 调整授权或撤销

需要更改知识库范围时，撤销旧连接并创建新连接。撤销后旧凭据立即失去数据库授权；若系统凭据清理失败，界面会单独提示，但不会恢复访问。

工具名称、参数、返回字段和限制见 [MCP v1 契约](mcp-contract-v1.md)。常见连接问题见[故障排查](troubleshooting.md)。
