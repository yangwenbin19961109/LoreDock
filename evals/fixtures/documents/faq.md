# LoreDock 常见问题

## 是否需要安装数据库？

不需要。LoreDock 默认使用随应用提供的 SQLite，普通用户无需安装 PostgreSQL、Redis 或独立向量数据库。

## 是否必须联网？

不必须。已经下载本地模型后，资料解析、全文检索、向量检索和 MCP 本地访问都可以离线工作。

## 可以直接复制数据库备份吗？

不可以直接复制正在写入的主数据库文件。备份必须使用 SQLite backup API 或 WAL 一致性快照。

## Embedding 模型损坏怎么办？

模型校验失败时禁止加载该模型，并自动保留 BM25-only 搜索。重新下载成功后，应根据完整模型契约重建向量索引。

## 是否支持手机应用？

不支持。LoreDock 的产品范围是 Windows、macOS、Linux 桌面端，以及服务器上的 Web 管理界面。

## MCP 默认可以修改资料吗？

不可以。MCP 工具默认只读，写入和删除能力需要未来单独设计授权与确认流程。
