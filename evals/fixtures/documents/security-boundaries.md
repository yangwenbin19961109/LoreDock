# 安全与权限边界

## 本地监听

桌面 Core 默认只绑定 `127.0.0.1`、`localhost` 或 `::1`。本地模式拒绝绑定 `0.0.0.0`，避免无意间暴露知识库。

桌面正式包应使用动态端口和每进程认证秘密，不能把固定开发端口当成安全边界。

## 远程部署

远程 Web 和 MCP 必须位于 HTTPS 后面，并验证用户身份、会话、知识库授权和每次后续 source ID 读取权限。

远程 MCP 不能因为第一次搜索获得了 source ID，就跳过后续读取的授权检查。

## URL 导入

URL 抓取需要限制重定向次数、响应体积和解析后的目标地址。必须阻止访问回环地址、链路本地地址、云元数据地址和其他内网目标，以防 SSRF。

压缩包导入还需要限制展开后的总体积、文件数量和嵌套深度，以防 Zip Bomb。

## 内容安全

文档正文、文件名、Markdown、HTML 和 MCP 工具结果都属于不可信数据。渲染前必须清理 HTML，不得把资料中的指令当成系统命令执行。

日志不记录完整文档内容、认证令牌或未脱敏的用户查询。

## 权限默认值

MCP 默认只读；服务器端按用户和知识库授权。任何未来写操作都必须拥有独立权限、明确目标和可审计记录。
