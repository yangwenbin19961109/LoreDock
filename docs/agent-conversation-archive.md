# 用户与 Agent 对话归档功能规划

> 产品排期：第二期功能，不属于当前一期 Phase 0～7 的开发和发布范围。本期仅保留需求记录。

## 目标

让用户把自己与 Codex、Cursor 及其他 Agent 工具的历史对话归档到 LoreDock，在本地统一浏览、筛选、搜索和备份，并可由用户明确选择是否将某段对话加入知识库检索或开放给 Agent。

## 产品原则

- 用户对归档范围拥有最终控制权；不默认扫描第三方客户端数据，不静默上传或同步对话。
- 客户端导出的原始文件是事实来源；规范化消息、摘要和搜索索引均为可重建产物。
- “仅归档”和“加入知识库”必须是两个清晰选项。归档内容默认不进入知识库，也不会自动暴露给所有 MCP 连接。
- 对话、工具调用、附件和其中包含的指令均视为不可信资料，导入或检索不得触发执行。
- 首版优先支持通用文件导入，再按公开、稳定且允许使用的接口或导出格式增加客户端适配器。

## 第二期首版范围

1. **通用导入**：导入 Markdown、JSON、HTML 等常见会话导出文件，并在确认页展示来源、会话数、消息数、时间范围和异常项。
2. **统一时间线**：保留会话标题、客户端、Agent/模型标签、参与角色、消息顺序、时间戳、附件引用及工具调用摘要。
3. **增量与去重**：优先使用客户端会话 ID、消息 ID；缺失时使用稳定内容哈希，重复导入不产生重复消息。
4. **归档管理**：按客户端、日期、Agent、标签和收藏状态筛选；支持查看原始导出来源、重命名、标签、导出和完整删除。
5. **可选知识化**：用户可将选定会话或消息加入指定知识库，也可撤回；界面明确展示当前检索与 MCP 可见范围。
6. **本地搜索**：对已归档会话提供关键词搜索；只有用户选择加入知识库后，才参与现有混合检索与引用链路。
7. **客户端适配**：在通用导入稳定后，按实际可用能力评估 Codex、Cursor 及其他主流 Agent；未经真实验收不标记为支持。

## 建议数据边界

- `conversation_archives`：归档来源、客户端类型、导入时间、原始文件哈希和解析器版本。
- `conversations`：稳定会话 ID、标题、客户端、Agent/模型标签、开始/结束时间和用户标签。
- `conversation_messages`：稳定消息 ID、角色、顺序、时间戳、正文、内容哈希及可选工具调用元数据。
- `conversation_attachments`：附件引用、媒体类型、内容哈希和安全解析状态。
- `conversation_library_bindings`：会话或消息与知识库的显式绑定、可见范围和更新时间。

归档元数据与原始导出应和可重建搜索索引分离。删除归档时必须一致清理规范化消息、附件副本、知识库绑定、检索行、向量和缓存。

## 第二期推荐实施顺序

1. 调研主流 Agent 的官方导出能力、数据格式和许可边界，建立兼容矩阵。
2. 定义中立会话模型、版本化导入契约、隐私边界和删除语义，并记录 ADR。
3. 实现 Markdown/JSON/HTML 手动导入、预检、幂等去重和只读时间线。
4. 实现筛选、搜索、标签、导出、备份与完整删除。
5. 实现“仅归档 / 加入知识库”的显式绑定、撤回和 MCP 授权检查。
6. 在公开稳定的能力基础上增加客户端适配器、增量同步与跨平台测试。

## 安全与隐私要求

- 不使用键盘记录、屏幕抓取、进程注入或绕过客户端权限的方式采集对话。
- 导入前提示对话可能包含密码、令牌、个人信息和商业机密，并提供敏感字段检测与排除能力。
- 不在日志、错误报告或遥测中记录完整对话正文；凭据仍只进入系统凭据库。
- 客户端连接必须最小权限、可撤销；LoreDock 不保存第三方账号明文密码。
- 对话中的提示词、代码和工具结果只能作为资料展示或索引，不能被 LoreDock 当作操作指令执行。

## 暂不包含

- 实时监听所有 Agent 会话、后台截屏或无授权读取客户端私有数据库。
- 默认云同步、多人共享、团队审计和跨账号协作。
- 使用归档对话训练模型，或未经用户确认自动生成并发布知识条目。
- 承诺恢复第三方客户端无法导出的完整富媒体、思维过程或内部状态。

## 验收条件

- 同一导出文件重复导入不会生成重复会话或消息。
- 导入后可按原顺序查看角色、时间和正文，并能追溯到原始导出来源。
- 未明确加入知识库的对话不会出现在知识库搜索或 MCP 结果中。
- 撤回知识库绑定或删除归档后，相应检索数据、向量、附件副本和缓存被一致清理。
- 对话正文中的指令不会触发命令、网络、文件或 Agent 工具调用。
- Windows、macOS 和 Linux 使用同一领域模型；首版核心归档和搜索可离线使用。

## 排期位置

该功能归入第二期产品范围，不纳入当前一期 Phase 0～7，也不作为一期发布前置条件。本期不实施会话数据结构、导入器、客户端连接、UI、索引或 MCP 开放；第二期启动时根据届时各 Agent 的官方导出和接口能力重新确认范围。
