# LoreDock 故障排查

## Core 不可用

先使用界面的“重新启动 Core”。若连续恢复失败，完全退出 LoreDock 后重新打开。仍失败时记录界面显示的错误码和脱敏诊断文本；不要发送数据库、原始资料或系统凭据。

## 导入失败

确认文件类型受支持、单文件不超过 100 MiB，并检查剩余磁盘空间。批量导入中的失败项可以重试；重复内容会返回已有资料。URL 导入只接受公开 HTTP/HTTPS 页面，内网、回环地址、非标准端口、压缩响应和过大页面会被拒绝。

## 搜索没有结果

确认资料状态为“就绪”。本地模型缺失或损坏时，可以继续使用关键词搜索，或在设置页重新安装模型。索引损坏时 LoreDock 会从原始资料自动重建。

## 备份无法恢复

先运行完整性验证。恢复只接受 LoreDock 管理的备份；校验失败不会替换当前数据。恢复成功需要 Core 重启，重启后再检查资料与搜索。

## Agent 无法连接

保持 LoreDock 正在运行，并确认 Agent 与 LoreDock 位于同一台电脑、同一系统用户下。重新复制连接说明，不要手工复制令牌。若授权知识库不正确，撤销旧连接并创建新连接。

当前一期不提供日志包导出。界面的诊断内容已经过脱敏，可复制错误码与状态文本用于排查。
